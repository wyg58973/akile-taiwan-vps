## NAT 共享 IP 和独立 IPv4 的实际差别

NAT 意味着你拿到的是一个共享公网 IPv4 上的端口映射。你没法定制解析把域名指到自己的 80/443，除非商家另外给端口转发；IP 信誉由同一地址上的所有用户共享，别人跑垃圾流量导致整段被拉黑，你也一起承担。做流媒体解锁、注册本地服务这类对 IP 干净度敏感的事，NAT 款的翻车概率明显更高。

独立 IPv4 就是另一回事。TWLite-Mini 给 1 个独立地址，域名、证书、反向代理、邮件发送记录的 PTR 都能自己掌控。一年多花 ¥99.91 换这些能力，对任何打算长期用的场景都是划算的。

## 标称端口和你能跑到的速度差多远

0.2Gbps、1Gbps、2Gbps 是机房网口的能力上限，不是跨境实速。算一下流量更直观：1TB 在 200Mbps 下跑满约 11 小时，1.5TB 在 1Gbps 下约 3.3 小时，5TB 在 2Gbps 下约 5.6 小时。也就是说这些套餐的月流量额度几个小时就能烧完，端口数字大只在短时突发时有意义，真正卡住你的是月流量。

跨境速度还要看运营商互联和晚高峰。标称 1Gbps 的台湾机器，晚 8 点到 11 点跑到几十 Mbps 是常态，白天可能翻几倍。买之前先想清楚你是要"短时间快"，还是要"全天候稳"。
